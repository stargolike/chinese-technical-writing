# 中文技术文档交付前审校清单

根据文档类型选用相关项目，不要求每篇文档都包含所有部分。

## 读者和结构

- [ ] 文档开头说明主题、目标或适用范围。
- [ ] 内容顺序贴合读者的任务；前置条件先于操作步骤。
- [ ] 标题能概括章节内容，层级连续且不超过四级。
- [ ] README、教程、API 参考等结构匹配文档类型，没有为填模板而制造内容。

## 技术准确性

- [ ] 命令、路径、参数、默认值、示例、版本和链接与项目材料一致。
- [ ] 操作步骤包含必要输入和预期结果；条件分支写清楚。
- [ ] 未知或未验证的事实没有写成确定结论。
- [ ] 示例中的密钥、地址和占位符清楚，不会被误认为真实凭据。

## 中文表达

- [ ] 每段只有一个中心，主要结论尽量放在段首。
- [ ] 长句、长段和一逗到底的表达已复查。
- [ ] 主语、操作对象和代词指向清楚。
- [ ] 语气平实，少用口语、双重否定和多余修饰。
- [ ] 术语和缩写首次解释，后文写法一致。

## 格式与可读性

- [ ] 中文与英文的空格、数字格式和标点使用一致。
- [ ] 中文数字均为半角，单位、范围、金额表达清楚。
- [ ] 代码、命令、路径和配置项正确使用行内代码或代码块。
- [ ] 列表项结构平行；标题末尾没有不合适的点号。
- [ ] 引用、外部图片和关键参考资料注明来源。
- [ ] 链接文字说明去向，链接目标与上下文相关。
